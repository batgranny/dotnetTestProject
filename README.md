In order to create a new project in dotnet in the terminal:
mkdir ~/Documents/learning/dotnet/SOMEFOLDER
dotnet new console ~/Documents/learning/dotnet/SOMEFOLDER

Then in VSCode file > open folder > ~/Documents/learning/dotnet/SOMEFOLDER

The code is kept in the Program.cs file

You can debug the code in VScode by f5 (the globe button on the bottom left of thr mac keyboard is the fn key)

or in the terminal 

dotnet build
dotnet run
